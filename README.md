# Лабораторная работа №1. Введение в Python

Репозиторий содержит решения 11 заданий лабораторной работы №1 по дисциплине «Алгоритмы и программирование на Python».

## Структура проекта
- `tasks/` — модули с логикой каждого задания (инкапсулированы в функции `solve()`).
- `main.py` — верхнеуровневый модуль для запуска заданий (сложность Medium).
- `tests/` — тесты с использованием `pytest` (сложность Well-done).
- `report/` — отчет по лабораторной работе.
